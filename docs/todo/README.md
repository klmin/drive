# todo

나중에 이어서 할 작업을 주제별 파일로 남긴다. 새 세션·다른 사람이 git 만 보고 이어갈 수 있게 쓰는 것이 목적이다.

## 규칙
- 파일 하나 = 주제 하나(`upload-session.md` 처럼). 항목은 체크박스.
- 항목마다 **왜**(배경·위험), **어디**(파일·메서드), **끝났다는 기준**(테스트·확인 방법)을 적는다. "무엇을"만 적으면 다음 사람이 다시 조사해야 한다.
- 끝낸 항목은 지우지 말고 `[x]` + PR 번호를 남긴다. 한 파일이 모두 끝나면 파일을 지우고 관련 설계 문서에 결과를 옮긴다.
- 설계 결정 자체는 `docs/design/` 에, 여기에는 할 일만.
