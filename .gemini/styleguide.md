# 리뷰 가이드

## 언어
- 리뷰 코멘트와 요약은 한국어로 작성

## 우선순위 (높은 순)
1. 버그, 예외 처리 누락, null 처리
2. 보안: 권한 검사 누락, 테넌트 간 데이터 노출, 입력 검증
3. 트랜잭션 경계, 동시성(락, 중복 처리, 재시도)
4. 스토리지(S3 호환): 멀티파트 업로드 중단 시 정리, 삭제 큐 처리, 대용량 파일 메모리 사용
5. DB: Flyway 마이그레이션 호환성, 인덱스, N+1 쿼리
6. 테스트 누락

## 생략할 것
- 네이밍, 포맷팅, 취향 수준의 리팩터링 제안
- 이미 동작하는 코드에 대한 "이렇게도 할 수 있다" 식의 대안 제시

## 프로젝트 맥락
- Java 21, Spring Boot 3.5, JPA와 jOOQ를 함께 사용 (조회·upsert·배치는 jOOQ)
- PostgreSQL, Redis, ShedLock 분산 스케줄러
- 멀티 테넌트 구조이므로 테넌트 식별자 누락을 특히 주의
